## 关键进展

### 1. 澄清 F450 ≠ 飞控

F450 是经典四轴**机架**（450mm 轴距），飞控需另购 F405 并刷 INAV 固件。

### 2. 硬件架构（系统论）

```
输入          处理                    输出
─────────────────────────────────────────────
遥控 CH1-4 → F405 飞控 (INAV)    → 四合一电调 → 2212 电机
遥控 CH5   → INAV 模式（ANGLE 自稳，无 GPS）
遥控 CH6   → Arduino Nano       → MG90S 舵机 → 拉锁收放
（无 GPS，视距内手动飞行）
```
