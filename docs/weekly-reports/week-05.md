## 本周重点：方案调整

本周主要围绕载重释放机构进行方案复盘和调整。上周确定的方案是使用舵机带动拉杆，控制单向卡舌完成挂载与释放。但经过进一步讨论和实际准备后，发现该方案虽然理论上可行，但对当前项目进度来说工程问题较多，制作和调试成本偏高。

舵机方案需要同时解决机械结构加工、拉杆传动、卡舌复位、摩擦阻力、舵机固定、遥控通道控制、Arduino 供电与代码调试等问题。每一个环节都可能影响最终释放效果，尤其是在材料采购不充分、剩余时间有限的情况下，继续推进该方案存在较大延期风险。

因此，本周决定放弃舵机挂钩方案，改用电磁铁进行载重与释放。电磁铁方案的结构更简单，只需要在无人机底部安装电磁铁，在载重物顶部增加可被吸附的铁片或金属连接件。通电时电磁铁吸住载重物，断电后载重物脱离，从而实现释放。

## 方案变更原因

### 原舵机方案的问题

- 机械结构较复杂，需要制作漏斗导向槽、单向卡舌、拉杆和复位结构。
- 对加工精度要求较高，卡舌角度、拉杆长度和舵机行程都需要反复调试。
- 舵机释放时可能出现卡顿、拉不动或复位失败的问题。
- 需要额外完成 Arduino 与接收机辅助通道的联动测试。
- 购买的材料不够完整，短时间内难以完成稳定可靠的机构制作。
- 剩余时间有限，继续推进舵机方案可能影响最终演示效果。

### 改用电磁铁方案的原因

- 结构更简单，减少了复杂机械传动。
- 制作速度更快，更适合当前时间安排。
- 释放逻辑清晰：通电吸附，断电释放。
- 对机械加工精度要求较低，只需要保证电磁铁和载重物金属片接触可靠。
- 更容易进行桌面测试和上机测试。
- 后续可以通过调整电磁铁位置、金属片面积和载重重量来快速优化效果。

## 释放机构设计

- 选定方案：电磁铁吸附式载重释放机构。
- 基本原理：电磁铁安装在无人机底部，载重物顶部固定铁片或金属吊点。电磁铁通电后吸附载重物，无人机携带载重物飞行；需要释放时切断电源，电磁铁失去磁力，载重物自然脱落。

## 控制链路

原计划控制链路：

```text
遥控器辅助通道 -> 接收机 -> Arduino -> 舵机 -> 机械挂钩释放
```

调整后控制链路：

```text
电源 / 控制开关 -> 电磁铁通电吸附 -> 断电释放载重物
```

后续需要根据实际硬件条件确认是否使用遥控器辅助通道控制电磁铁通断电。如果时间不足，可先完成手动通断电或简单开关控制的载重演示，再进一步优化为遥控释放。

## 遇到的问题

| 问题 | 尝试方案 | 结果 |
|------|----------|------|
| 舵机挂钩方案工程复杂度较高 | 继续拆解机械结构、拉杆、卡舌和 Arduino 控制流程 | 发现需要解决的问题过多，短时间内难以稳定实现 |
| 购买材料不够完整 | 评估是否继续补充材料并推进舵机方案 | 由于时间不足，继续采购和调试风险较大 |
| 舵机释放机构可靠性不确定 | 讨论是否降低机构复杂度 | 决定放弃舵机方案，改用电磁铁吸附释放 |
| 电磁铁方案需要验证吸附力 | 计划进行桌面载重测试 | 待测试不同重量下的吸附稳定性 |
| 电磁铁安装可能影响重心 | 后续将电磁铁布置在机体底部中心位置 | 待上机后检查重心和飞行稳定性 |
