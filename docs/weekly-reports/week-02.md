### 重大方案变更：四合一 → 分体电调

原计划采购「飞盈佳乐 55A 四合一飞塔」，因以下原因最终改为分体方案：
1. 商家首次发错电调（接口不符）
2. 补购四合一后，焊接时接口焊盘烫坏
3. 综合评估后决定改为 **4 个分体电调 + 独立分电板 (PDB)**

| 对比 | 原方案（四合一） | 实际方案（分体） |
|------|------------------|-------------------|
| 电调 | 四合一 ×1 | 分体电调 ×4 |
| 供电 | 内置 | 独立 PDB 分电板 |
| 焊接量 | ~14 焊点 | ~32+ 焊点 |
| 优点 | 集成度高 | 单路故障可单独更换 |
| 缺点 | 整体更换成本高 | 焊点多、布线复杂 |

| 分体电调焊点数量激增（~32+ vs ~14） | 逐路焊接，每路完成后万用表测短路 | ✅ 全部通路正常 |

### 经验教训

1. **采购前核对接口规格**：飞控与电调的排线接口、电池与电调的电源接口（XT60/XT30/T 插等）需在下单前逐一确认，避免发错或不兼容。
2. **焊接大焊盘需足够功率**：60W+ 烙铁 + 380°C 以上温度，主电源焊盘散热快，温度不够容易长时间加热导致周围元件损坏。
3. **关键元件备一份**：电调/飞控类核心板卡建议多备一块，焊接失误或来料问题不至于让进度停滞。
4. **四合一 vs 分体各有取舍**：四合一集成度高但整体更换成本高；分体电调焊点多但单路故障可单独更换。初次焊接经验不足时，分体方案容错性更好。
