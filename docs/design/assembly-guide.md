# F450 组装与调试指南

> 基于 Week 1 AI 协作结论整理，对应硬件：F450 + 乐迪 F405/55A 四合一 + 2212-980KV + 21700-LA 3S + 8CH 遥控。  
> **无 GPS**：视距内飞行，使用 INAV 自稳模式，不配置 GPS/罗盘。

## 第一阶段：工具与辅料

- [ ] 60W+ 电烙铁、焊锡、助焊剂
- [ ] 内六角螺丝刀、243 可拆螺丝胶
- [ ] 3M VHB 或 M3 减震柱
- [ ] 扎带、热缩管、双面胶
- [ ] INAV Configurator（电脑端）

## 第二阶段：机架组装

1. 4 × 2212-980KV 固定机臂末端，**每颗螺丝点 243 螺丝胶**
2. 机臂固定下中心板；同色机臂朝前作机头
3. F450 下中心板分电铜箔**不接电**（四合一方案）

## 第三阶段：动力焊接

### 电调主电源

1. XT60 线、电容引脚、电调 ± 焊盘：**两面分别上锡后融合焊接**
2. 电容极性：长脚 +，`-` 标记端为 -
3. 建议 380–400°C，60W+ 烙铁

### 电机线（推荐）

- 剪掉 3.5mm 香蕉头，12 根线直焊四合一 M1–M4 焊盘
- 转向错误：INAV 软件反转，或对调任意两根线

### 飞塔安装

1. 四合一电调固定中心（减震圈）
2. **10P 转 8P 排线**连接 F405 飞控
3. 飞控箭头指向机头，VHB/减震柱固定

### 接收机

- VCC(5V) / GND / SBUS → 飞控对应焊盘
- 接收机用胶+扎带固定，天线外置

## 第四阶段：INAV 调参（全程无桨）

1. USB 连电脑，刷 INAV 固件
2. 校准加速度计（水平桌面）
3. Ports：接收机 UART → Serial RX（**无需配置 GPS 端口**）
4. Configuration：Serial SBUS；DSHOT600
5. 遥控器对频，Receiver 页检查通道
6. 设 ARM 开关；CH5 映射 **ANGLE 自稳模式**（视距内手动飞行）
7. 插电池，Motor Test 检查 1–4 号转向

### 21700-LA 电池 INAV 设置

| 参数 | 值 |
|------|-----|
| Warning Voltage | 3.2V/cell |
| Minimum Voltage | 2.9V/cell |

## 第五阶段：首飞

1. 1045 正反桨按转向图安装
2. 空旷草地，无桨测试后再装桨
3. 解锁 → 缓推油门离地

## 安全 Checklist

- [ ] 电容已焊且极性正确
- [ ] 电机螺丝未顶穿线圈
- [ ] 无桨完成 Motor Test
- [ ] 电池 XT60 无短路
- [ ] 低压报警已设
