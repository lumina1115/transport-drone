# F450 组装与调试指南

> 基于 Week 1–2 AI 协作结论整理，对应硬件：F450 + F405(INAV) + 2212-980KV + 分体电调 ×4 + PDB + 21700-LA 3S + FlySky 8CH 遥控。  
> **无 GPS**：视距内飞行，使用 INAV 自稳模式，不配置 GPS/罗盘。  
> ⚠️ **Week 2 方案变更**：四合一电调 → 分体电调 ×4 + 分电板 (PDB)。

## 第一阶段：工具与辅料

- [ ] 60W+ 电烙铁、焊锡、助焊剂
- [ ] 内六角螺丝刀、243 可拆螺丝胶
- [ ] 3M VHB 或 M3 减震柱
- [ ] 扎带、热缩管、双面胶
- [ ] INAV Configurator（电脑端）

## 第二阶段：机架组装

1. 4 × 2212-980KV 固定机臂末端，**每颗螺丝点 243 螺丝胶**
2. 机臂固定下中心板；同色机臂朝前作机头
3. F450 下中心板分电铜箔**不接电**（使用独立 PDB 分电板）

## 第三阶段：动力焊接

### 分电板 (PDB) 主电源

1. XT60 电源线焊接至 PDB 输入端（注意正负极性）
2. 电容焊接至 PDB 主电源焊盘（如有）
3. 建议 380–400°C，60W+ 烙铁
4. **焊后必测**：万用表蜂鸣档测 PDB 输入端正负极是否短路

### 分体电调焊接（4 路）

1. 4 个分体电调输入端分别焊接至 PDB 对应的 4 路输出焊盘（V+ / GND）
2. 电调信号线（通常为 3 线：信号 / VCC / GND）连接至飞控 M1–M4 输出
3. 电容极性：长脚 +，`-` 标记端为 -
4. **每焊完一路，万用表测该路是否短路**，确认无误后再焊下一路

### 电机线（推荐）

- 剪掉 3.5mm 香蕉头，12 根线直焊分体电调 M1–M4 输出端
- 转向错误：INAV 软件反转，或对调任意两根线

### 飞控安装

1. 分体电调均匀布置在机臂或中心板上（扎带固定）
2. F405 飞控通过排线连接，箭头指向机头
3. VHB 或 M3 减震柱固定飞控

### 接收机

- VCC(5V) / GND / SBUS → 飞控对应焊盘
- 接收机用胶+扎带固定，天线外置

## 第四阶段：INAV 调参（全程无桨）

1. USB 连电脑，刷 INAV 固件
2. 校准加速度计（水平桌面）
3. Ports：接收机 UART → Serial RX（**无需配置 GPS 端口**）
4. Configuration：Serial SBUS；DSHOT600
5. 遥控器对频，Receiver 页检查通道
6. 设 ARM 开关；CH5 映射 **ANGLE 自稳模式**（视距内手动飞行）
7. 插电池，Motor Test 检查 1–4 号转向

### 21700-LA 电池 INAV 设置

| 参数 | 值 |
|------|-----|
| Warning Voltage | 3.2V/cell |
| Minimum Voltage | 2.9V/cell |

## 第五阶段：首飞

1. 1045 正反桨按转向图安装
2. 空旷草地，无桨测试后再装桨
3. 解锁 → 缓推油门离地

## 安全 Checklist

- [ ] PDB 每路电调供电焊点无短路（万用表确认）
- [ ] 分体电调信号线 M1–M4 对应正确
- [ ] 电容已焊且极性正确
- [ ] 电机螺丝未顶穿线圈
- [ ] 无桨完成 Motor Test
- [ ] 电池 XT60 无短路
- [ ] 低压报警已设
