# 收放机构设计文档

> 课程核心难点：无现成技术路线，需自行设计并验证。  
> 目标：在 **150g** 载重下可靠释放，机构自重 ≤ **50g**。  
> 基于 Week 1 AI 协作结论，2026-05-31

## 选定方案（Week 1 暂定，Week 4 确认）

**方案名称**：舵机拉锁式（Quick Release Pin）

**工作原理**：

1. 物资用绳绑好，绳头打闭合圈
2. 3D 打印插销穿过绳圈，舵机中位时锁紧
3. 遥控器 CH6 触发 → Arduino → 舵机旋转 90° → 插销拔出 → 物资靠重力脱落

**主要零件**

| 零件 | 来源 | 数量 | 状态 |
|------|------|------|------|
| MG90S 金属齿舵机 | 淘宝 | 2（1 备用） | ⬜ 待购 |
| 3D 打印插销 + 底座 | PLA 自打 | 1 套 | ⬜ Week 4 |
| Arduino Nano | 已有 | 1 | ✅ |
| 5V UBEC 独立供电 | 淘宝 | 1 | ⬜ 待购 |

**3D 模型文件**：`cad/`（Week 4 添加）

## 控制逻辑

```
遥控器 SWB (CH6)
    ↓ PWM 1000/2000μs
接收机 CH6 引脚 → Arduino D2 (pulseIn)
    ↓
Arduino D9 → MG90S 信号线
    ↓
舵机 0° 夹紧 / 90° 释放
```

| 参数 | 值 |
|------|-----|
| 触发通道 | CH6 |
| Arduino 输入 | D2 |
| Arduino 输出 | D9 |
| PWM 阈值 | >1500μs = 释放 |
| 夹紧角度 | 0°（桌面测试后调整） |
| 释放角度 | 90°（桌面测试后调整） |

### 供电注意

- MG90S **禁止**接 Arduino 5V 引脚供电
- 使用电调 BEC 或独立 UBEC 5V 供电
- 接收机 GND 与 Arduino GND **必须共地**
