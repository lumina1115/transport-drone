## 方案变更记录

### 四合一电调 → 分体电调 + 分电板（Week 2）

| 对比 | 原方案（四合一） | 实际方案（分体） |
|------|------------------|-------------------|
| 电调 | 飞盈佳乐 55A 四合一 ×1 | 分体电调 ×4 |
| 供电 | 四合一内置 | 独立分电板 (PDB) |
| 焊接量 | ~14 焊点 | ~32+ 焊点 |
| 优点 | 集成度高、走线简洁 | 单路故障可更换、成本灵活 |
| 缺点 | 整体更换成本高 | 焊点多、布线复杂 |

> 变更原因：四合一电调首次商家发错接口，补购后焊接烫坏，最终改为分体电调方案以降低单点故障风险和更换成本。

## 无 GPS 飞行说明

- 飞行范围：**视距内（VLOS）**，不启用 GPS 定点/返航
- INAV 仍可用：**ANGLE（自稳）** 模式辅助平飞；收放时由飞手手动控油门与位置
- 不影响 Arduino 收放：CH6 → Arduino → 舵机链路不变
