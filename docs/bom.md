## 无 GPS 飞行说明

- 飞行范围：**视距内（VLOS）**，不启用 GPS 定点/返航
- INAV 仍可用：**ANGLE（自稳）** 模式辅助平飞；收放时由飞手手动控油门与位置
- 不影响 Arduino 收放：CH6 → Arduino → 舵机链路不变
