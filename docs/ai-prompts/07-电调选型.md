# 07 · 电调选型（四合一 vs 单体）

**来源**：Google Gemini · 2026-05-31  
**原始文件**：`无人机电调选购指南-GoogleGemini_2026-05-31-19-45-48.md`

## 讨论主题

- 电调作用（DC→三相 AC、调速、保护）
- 10P 转 8P 排线说明
- 乐迪 F405 + 飞盈佳乐 55A 四合一评估
- 四合一 vs 4 个单体电调
- 焊接不可避免的部分

## 关键结论

### 最终选型

**乐迪 F405 飞控 + 飞盈佳乐 55A 四合一电调飞塔**

| 优势 | 说明 |
|------|------|
| 10P 转 8P 排线 | 飞控↔电调信号免焊 |
| 55A 冗余 | 2212 电机单路 ~15–20A，余量充足 |
| BLHeli_32 | 支持 DSHOT600，免电调行程校准 |
| 电流回传 | INAV OSD 显示实时电流 |

### 必须焊接的部分（14 个焊点）

- XT60 电源正负极 × 2
- 1000μF 电容（并联电源，注意极性）× 2 引脚
- 4 电机 × 3 线 = 12 焊点

### 不推荐

- 好盈天行者 15A 单体电调 × 4（走线混乱、无 Telemetry、BEC 并联风险）
