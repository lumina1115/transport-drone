## 关键结论

### 抓放方案对比（AI 推荐排序）

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **舵机拉锁式** | 插销穿绳圈，舵机旋转释放 | 极轻、省电、结构简单 | 只能放，不能空中再抓 |
| 乐高齿轮夹爪 | 舵机驱动双向齿轮 | 可抓可放、易试错 | 自重大、振动易松 |
| 电磁铁吸附 | 5V 电磁铁 + 物资铁片 | 无机械卡死 | 耗电、剩磁可能不脱落 |

**倾向方案**：舵机拉锁式（Week 4–5 再最终确认）

### 控制链路

```
遥控器 CH5/CH6 → 接收机 PWM → Arduino Nano → MG90S 舵机 → 收放机构
飞控 CH1–4 ← 接收机 IBUS/SBUS（飞行控制）
```
