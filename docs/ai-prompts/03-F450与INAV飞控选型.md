## 讨论主题

- F450 = **机架型号**（450mm 轴距），不是飞控
- INAV vs APM vs QQ 飞控对比
- F450 + F405 飞控 + INAV 固件架构
- 飞控连接电脑、减震安装

## 关键结论

### 铁三角关系

| 角色 | 选型 |
|------|------|
| 骨骼 | F450 标准机架（含中心板 + 4 机臂） |
| 大脑硬件 | STM32 F405 导航飞控（带气压计、多 UART） |
| 灵魂软件 | **INAV 固件（免费开源）** |

### 为什么选 INAV + F405（而非 APM 2.8）

- INAV 悬停算法更现代，载重时重心变化修正更快
- 图形化 INAV Configurator，新手友好
- GPS 定点悬停对收放操作至关重要
- APM 2.8 芯片算力无法运行 INAV

### 必购配套

- **GPS 模块**：M8N/M10，**必须带内置罗盘**
- **减震**：3M VHB 泡棉胶或 M3 硅胶减震柱（约 ¥3–5）
- **遥控器 + 接收机**：必须购买，6 通道以上

### Arduino 与飞控分工

| 硬件 | 角色 |
|------|------|
| F405 飞控 (INAV) | 飞行平衡、GPS 悬停 |
| Arduino Nano | 读取 CH6，控制舵机收放 |
