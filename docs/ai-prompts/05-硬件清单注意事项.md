## 关键结论

### 抓放功能对飞控的硬性要求

- QQ 飞控**不可用**（无定高定点，收放时无法稳定悬停）
- 最终路线：**F450 机架 + F405 飞控 + INAV**

### 遥控器通道分配（6 通道方案）

| 通道 | 用途 |
|------|------|
| CH1–4 | 飞控飞行（油门/偏航/俯仰/横滚） |
| CH5 | INAV 模式切换（手动 / GPS 悬停） |
| CH6 | Arduino 收放触发 |

### 调试顺序（AI 建议）

1. 桌面：Arduino + 接收机 CH6 + 舵机
2. 无桨：四电机转向 + 电调校准
3. 总装试飞

### 舵机供电铁律

**禁止**用 Arduino 5V 直供 MG90S；需独立 5V BEC/UBEC
