## 讨论主题

- F405 + 55A 四合一电调下的电池选型
- LiPo vs Li-ion (18650/21700)
- 免焊接电池方案
- 力神 21700-LA 参数确认

## 关键结论

### 已选电池规格

| 参数 | 数值 |
|------|------|
| 电芯 | 力神 21700-LA |
| 配置 | 3S1P（11.1V / 12.6V 满电） |
| 容量 | 4000mAh |
| 持续放电 | **45A** |
| 重量 | ~240g |
| 排列 | 品字形 |

### 与 2212-980KV + F450 的匹配

- 3S 电压 + 980KV + 1045 桨：经典 F450 动力组合，可行
- 45A 放电能力远超普通 18650，无需 INAV 限流
- 21700 优于 18650：更高容量 + 更强放电

### INAV 电池参数设置（Li-ion）

| 参数 | 建议值 |
|------|--------|
| 单节标称电压 | 3.6–3.7V |
| 低压报警 | 3.2V/节（总 9.6V） |
| 截止电压 | 2.9V/节 |

### 采购备注

- 接口：XT60 母头（电池端）
- 可买成品 21700 航模电池组，无需自焊
