## 关键结论

### 材料兼容性：✅ 可完成组装飞行

| 部件 | 评估 |
|------|------|
| 2212-980KV + 1045 桨 | F450 标准动力，优秀 |
| F405 + 55A 四合一 | 电流冗余大，安全 |
| 21700-LA 3S 45A | 与动力完美匹配 |
| 8 通道 2.4G 遥控 | 可用，接收机可能需杜邦线焊飞控 |

### 待确认/补充

- [ ] GPS 模块（INAV 定点悬停必备）
- [ ] F450 整套机架（含 4 机臂 + 中心板 + 螺丝）
- [ ] 60W+ 电烙铁、243 螺丝胶、热缩管、扎带
- [ ] 接收机 SBUS 线 → 飞控 5V/GND/RX 焊接

### 组装阶段概要

1. **准备**：工具与辅料确认
2. **机架**：固定电机（螺丝胶）+ 组装机臂
3. **焊接**：电调电源+电容 → 电机线 → 飞塔叠加 → 接收机
4. **调参（无桨）**：刷 INAV → 校准 → SBUS → 电机转向
5. **首飞**：装桨 → 户外解锁试飞

详细步骤见 `docs/design/assembly-guide.md`
