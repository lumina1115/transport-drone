# 运输无人机 · Transport Drone

> 载重运输无人机课程项目 — 目标载重 **150g**，预算控制在 **200–300 元**（淘宝采购）。

## 项目概述

针对山区、交通不便等场景，开发一台具备**稳定飞行**与**货物收放**能力的四轴运输无人机原型。

| 项目 | 说明 |
|------|------|
| 载重目标 | **150g**（有效载荷，不含机构自重） |
| 团队规模 | 2 人 |
| 周期 | 6 周 |
| 预算 | 200–300 元 |

## 技术路线

```
输入 (Input)    →  处理 (Processing)  →  输出 (Output)
遥控信号           飞控 + Arduino          电机推力
（可选传感器）      收放控制逻辑            舵机/马达收放
```

**核心难点**：收放机构无现成方案，需自行设计（3D 打印或乐高类零件）+ Arduino 控制 + 飞行中遥控信号稳定传输。
